# eSports Arena Manager

eSports Arena Manager es una plataforma frontend para la gestión de torneos de videojuegos competitivos. Su objetivo es permitir la visualización de torneos, consulta de detalles, inscripción de jugadores o equipos, gestión de equipos y actualización de perfiles de jugador.

Este proyecto corresponde a la base de la Evaluación Parcial 1 y fue desarrollado utilizando únicamente tecnologías frontend, sin frameworks ni backend.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Vistas principales

- Inicio
- Listado de torneos
- Detalle de torneo
- Inscripción a torneo
- Gestión de equipo
- Perfil de jugador

## Funcionalidades implementadas

- Catálogo de torneos cargado desde arreglos de JavaScript.
- Torneos destacados y próximos cierres de inscripción.
- Filtros por juego, estado, fechas y nombre.
- Detalle de torneo con participantes, calendario de partidas, posiciones y premios.
- Creación y gestión de equipos.
- Inscripción a torneos con validaciones.
- Validación de perfil, correo electrónico y contraseña.
- Diseño visual basado en la paleta Táctico rojo.

## Ejecución del proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir `index.html` mediante Live Preview.

## Repositorio

El proyecto se mantiene mediante Git y GitHub, con commits que registran los avances realizados durante el desarrollo.


## Pruebas realizadas

- Filtros por juego, estado, fecha y nombre.
- Mensaje informativo cuando no existen resultados.
- Validación de apodo, correo electrónico y contraseña.
- Restricciones para inscripciones repetidas, equipos inactivos, sanciones y cupos.
